# ZVERTURET

Адаптивная киноафиша на React с минималистичным чёрным интерфейсом и цветными постерами

## Возможности

- Каталог из 28 фильмов с поиском и фильтрами по жанрам
- Избранное с сохранением в `localStorage`
- Полноэкранное бронирование сеанса и мест
- Схема зала на 9 рядов по 12 мест с расчётом цены
- Просмотр и отмена билетов
- Переключение тёмной и светлой тем с сохранением выбора
- Адаптивная вёрстка для компьютера и телефона

## Запуск

```bash
npm install
npm run dev
```

Сборка проекта:

```bash
npm run build
```

## GitHub Pages

Публикация запускается автоматически через GitHub Actions при отправке изменений в ветку `main`

Открой настройки репозитория и выбери **Settings → Pages → Source → GitHub Actions**

## Файлы

- `src/App.jsx` — интерфейс каталога и логика приложения
- `src/styles.css` — темы и адаптивные стили
- `PROMPT.md` — единый промпт для GitHub Copilot по разделам
- `src/assets/zverturet-mark.png` — иконка бренда

Постеры загружаются с TMDB Images. Для них нужен интернет

GitHub Copilot не был подключён к этой среде. Код приложения собран и доработан здесь. Сводный промпт сохранён отдельно для использования с Copilot
